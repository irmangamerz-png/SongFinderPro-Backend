# Sistem 20 Kali + Cooldown 20 Jam + Mode Keluarga

Paket sistem ini mencakup pembatasan penggunaan sebanyak 20 kali, masa cooldown selama 20 jam setelah limit habis, serta fitur bypass **Mode Keluarga** menggunakan PIN rahasia `01092007`.

## Cara Instalasi & Menjalankan:
1. Ekstrak file ZIP ini.
2. Jalankan perintah `npm install` untuk menginstal dependensi.
3. Jalankan `npm start` untuk memulai server.
4. Akses melalui browser di `http://localhost:3000`.
