# SongFinder Pro - FINAL (OpenAI Railway)

Sistem lengkap **SongFinder Pro**[cite: 3] yang mencakup:
1. **Limit 20 kali** pencarian per sesi[cite: 3].
2. **Cooldown 20 jam** otomatis setelah limit habis[cite: 3].
3. **Mode Keluarga Tak Terbatas** dengan memasukkan PIN rahasia **`01092007`** yang disembunyikan aman di server[cite: 3].
4. **Dukungan Link YouTube/TikTok & Upload File Audio** dengan hasil pemutaran preview klip audio[cite: 3].

## Cara Instalasi:
1. Buat folder proyek, lalu masukkan file `server.js`, `package.json`, `.env`, `Dockerfile`, serta folder `public` berisi `index.html`.
2. Jalankan perintah `npm install` di terminal.
3. Jalankan `npm start` untuk mulai menjalankan server[cite: 3].
4. Buka browser dan akses `http://localhost:3000`[cite: 3].
